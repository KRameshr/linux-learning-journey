# Linux WordPress Deployment using LAMP Stack

This project demonstrates how to deploy a WordPress website on a CentOS 7 server using the LAMP stack.

## What is LAMP?

LAMP stands for:

- Linux – Operating System
- Apache – Web Server
- MariaDB/MySQL – Database
- PHP – Backend Language

## Project Objectives

- Install Apache Web Server
- Install MariaDB Database
- Install PHP
- Configure LAMP Stack
- Deploy WordPress Website

## Technologies Used

- CentOS 7
- Apache HTTP Server
- MariaDB
- PHP
- WordPress

## Project Architecture

User → Browser → Apache Web Server → PHP → MariaDB Database → WordPress
