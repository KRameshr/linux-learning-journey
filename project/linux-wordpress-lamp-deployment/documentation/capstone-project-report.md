# Linux Capstone Project Report

## Project Title

Deploy WordPress using LAMP Stack on CentOS 7

## Objective

To understand Linux server administration by installing and configuring a full LAMP stack and deploying a WordPress website.

## Tools Used

- CentOS 7
- Apache
- MariaDB
- PHP
- WordPress

## Outcome

Successfully deployed WordPress on a Linux server using LAMP stack.

This project demonstrates practical knowledge of:

- Linux server management
- Web server setup
- Database configuration
- WordPress deployment
